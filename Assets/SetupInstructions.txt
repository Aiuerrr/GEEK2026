SETUP INSTRUCTIONS
==================

This script implements the core typing mechanic. Follow these steps to set it up in your Unity Scene:

1. Create a Game Manager Object:
   - In the Hierarchy, right-click and create "Create Empty". Name it "TypingGameManager".
   - Drag the `Assets/Scripts/TypingGameManager.cs` script onto this object.

2. Create UI Canvas:
   - Right-click in Hierarchy -> UI -> Canvas.
   - (Optional) Set Canvas Scaler "UI Scale Mode" to "Scale With Screen Size".

3. Create UI Text Elements (TextMeshPro):
   - Right-click on Canvas -> UI -> Text - TextMeshPro.
   - Create 4 Text objects:
     A. "TextDisplay" (This will show the typing text).
        - Set Font Size to something readable (e.g., 36).
        - Enable "Rich Text" in the Extra Settings of the component (usually on by default).
     B. "TimerText" (Displays time).
     C. "FeedbackText" (Displays errors like "BŁĄD!").
     D. "StatsText" (Displays WPM and Errors at the end).

4. Link References:
   - Select the "TypingGameManager" object.
   - In the Inspector, you will see slots for "Text Display", "Timer Text", "Feedback Text", and "Stats Text".
   - Drag and drop the corresponding UI objects from the Hierarchy into these slots.

5. Configure Game Settings (Optional):
   - You can change the "Text To Type" string in the Inspector.
   - You can adjust "Initial Time" (default is 60 seconds).

6. Input System:
   - The script uses the New Input System (`UnityEngine.InputSystem`).
   - Ensure your Project Settings -> Player -> Active Input Handling is set to "Input System Package (New)" or "Both".
   - If you see compile errors, ensure the "Input System" and "TextMeshPro" packages are installed via Window -> Package Manager.

7. Play:
   - Press Play. The text should appear grey. Type the letters to turn them black.
   - Errors will show feedback and block progress.
   - Game ends when text is finished or timer hits 0.
